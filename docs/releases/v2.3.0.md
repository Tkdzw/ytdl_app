# YT Downloader v2.3.0 “Falcon”

**Released 17 November 2026** · Windows 10 / 11 (64-bit) · by Asher Naison

Codename **Falcon**: a trained falcon flies home on its own, and so does
this release. The app can now update itself. This is the last version you need to download
by hand.

---

## What's new
- **Update from inside the app.** *Settings → Updates → Check for updates*
  (also in About) finds the newest version on GitHub and installs it for you:
  the download is checked before it runs, Windows asks for permission, and the
  app reopens on the new version. When a new version is out, an **Update**
  button appears in the sidebar (you can switch that check off in Settings).

## Fixes
- The sidebar no longer always claims a yt-dlp update is available.

## Also in this release
Everything from 2.2.0, if you're coming from 2.1.1: faster downloads over
several connections, several videos at once, and automatic slow-down when
YouTube says there are too many requests. See
[v2.2.0](v2.2.0.md).

## Installing
Download **`YTDownloader_Setup.exe`** below and install over your current
version. Your settings and download history are kept. From now on, use
*Settings → Updates* instead.
